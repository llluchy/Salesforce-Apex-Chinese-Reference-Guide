Share a Feed Element (prior to Version 39.0)

Call a method to share a feed element.

Important

In API version 39.0 and later, shareFeedElement(communityId, subjectId, feedElementType, originalFeedElementId) isn’t supported. See Share a Feed Element (in Version 39.0 and Later).

Call shareFeedElement(communityId, subjectId, feedElementType, originalFeedElementId) to share a feed item (which is a type of feed element) with a group.
ConnectApi.ChatterLike chatterLike = ConnectApi.ChatterFeeds.likeFeedElement(null, '0D5D0000000KuGh');
