sfdw Namespace

Contains classes that describe Digital Wallet consumption card status and the alerts triggered when consumption crosses a threshold.

Available in: Enterprise Edition and Unlimited Edition orgs, or a Data One companion org of either edition, with Data 360 turned on.

The following are the classes in the sfdw namespace.

  • ConsumptionAlert Class
    Represents a Digital Wallet consumption alert that's triggered for a consumption card.
  • ConsumptionCard Class
    Represents a Digital Wallet consumption card, including its consumption, total entitlement, and related consumption alerts.
