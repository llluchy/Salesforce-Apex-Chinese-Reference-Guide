RulesAppln Namespace

The RulesAppln namespace contains output classes that store details about a rules-based application of payments and credits.

The rules are applied by using the applyPaymentsAndCreditsByRules invocable action. See Apply Payments and Credits by Rules Action in the Revenue Cloud Developer Guide.

The RulesAppln namespace includes these classes.

  • RulesApplicationResponse Class
  • RulesApplicationSummaryResponse Class
  • RulesApplicationErrorResponse Class
