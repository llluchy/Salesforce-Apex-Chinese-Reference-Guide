ConnectApi.AbstractRecommendation

A Chatter, custom, or static recommendation.

This class is abstract.

Superclass of:

  • ConnectApi.EntityRecommendation
  • ConnectApi.NonEntityRecommendation

    ConnectApi.NonEntityRecommendation isn’t used in version 34.0 and later. In version 34.0 and later, ConnectApi.EntityRecommendation is used for all recommendations.
