ConnectApi.InteractionsCapability

If a feed element has this capability, it has information about user interactions.

Subclass of ConnectApi.FeedElementCapability.

Property Name Type Description Available Version
count Long The number of individual views, likes, and comments on a feed post.This count appears in the UI under the feed post as the number of views, for example, “5 views.” 37.0
