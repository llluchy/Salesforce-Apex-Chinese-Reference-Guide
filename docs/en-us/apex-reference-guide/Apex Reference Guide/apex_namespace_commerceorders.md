# CommerceOrders Namespace

The `CommerceOrders` namespace provides classes and methods to place orders with integrated pricing, configuration, and validation.

See [CommerceOrders namespace](https://developer.salesforce.com/docs/atlas.en-us.262.0.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/apex_namespace_commerceorders.htm "HTML (New Window)") for more information about the available classes and methods.
