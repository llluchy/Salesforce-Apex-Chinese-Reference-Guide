# BucketType Enum

The types of values included in a bucket.

## Enum Values

The following are the values of the `Reports.BucketType` enum.

| Value | Description |
| --- | --- |
| `NUMBER` | Numeric values |
| `PICKLIST` | Picklist values |
| `TEXT` | String values |
