# ConnectApi.RefundSequenceItemInputRepresentation

The Order Payment Summary ID and amount for the individual refund items in a sequence. Each item has a payment method and refund amount to be processed for that method.

Subclass of [ConnectApi.AbstractBaseSequenceInputRepresentation](atlas.en-us.apexref.meta/apexref/apex_connectapi_input_abstract_base_sequence.htm "The sequence for refunds and payment credits.").
