# ConnectApi.LocationListInputRepresentation

A list of location identifiers used to specify locations excluded from routing consideration.

| Property | Type | Description | Required or Optional | Available Version |
| --- | --- | --- | --- | --- |
| `locations` | [List](atlas.en-us.apexref.meta/apexref/apex_methods_system_list.htm#apex_methods_system_list "Contains methods for the List collection type.")<String> | The list of location identifiers to exclude. Don't leave any identifier blank. The list can contain up to 100 items. | Required | 67.0 |
