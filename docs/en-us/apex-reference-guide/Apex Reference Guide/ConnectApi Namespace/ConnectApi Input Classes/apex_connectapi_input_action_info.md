# ConnectApi.ActionInfoInputRepresentation

Recommended action information.

| Property | Type | Description | Required or Optional | Available Version |
| --- | --- | --- | --- | --- |
| `name` | String | Name of the Lightning web component used for dynamically rendering the recommended action. | Optional | 60.0 |
| `parameters` | String | Parameters required for processing and displaying the recommended action. | Required | 60.0 |
