# ConnectApi.TopicsCapabilityInput

Assign topics to a feed element.

| Property | Type | Description | Required or Optional | Available Version |
| --- | --- | --- | --- | --- |
| `contextTopic​Name` | String | Name of the parent topic in the site to which the feed element belongs. | Optional | 38.0 |
| `topics` | [List](atlas.en-us.apexref.meta/apexref/apex_methods_system_list.htm#apex_methods_system_list "Contains methods for the List collection type.")<String> | List of topics to assign to the feed element. | Required | 38.0 |
