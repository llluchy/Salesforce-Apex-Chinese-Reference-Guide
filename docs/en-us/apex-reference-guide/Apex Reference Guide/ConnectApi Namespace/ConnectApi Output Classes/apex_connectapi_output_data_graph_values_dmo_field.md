# ConnectApi.DataGraphValuesDmoField

Represents the fields of the Data Model Object (DMO) that contains the JSON records for the data graph.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `capabilities` | [List](atlas.en-us.apexref.meta/apexref/apex_methods_system_list.htm#apex_methods_system_list "Contains methods for the List collection type.")<`Integer`\> | List of capabilities for the DMO field. | 61.0 |
| `dataType` | String | Data type of the DMO field. | 61.0 |
| `developerName` | String | Developer name of the DMO field. | 61.0 |
