# ConnectApi.FeedItemTopicPage

Feed item topic page.

:::tip Important
This class isn’t available in version 32.0 and later. In version 32.0
        and later, [ConnectApi.TopicsCapability](atlas.en-us.apexref.meta/apexref/apex_connectapi_output_topics_capability.htm) is used.
:::

| Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `canAssignTopics` | Boolean | `true` if a topic can be assigned to the feed item, `false` otherwise. | 28.0–31.0 |
| `topics` | `List<ConnectApi.​Topic>` | List of topics. | 28.0–31.0 |
