The status of a social post.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |

| `type` | [`ConnectApi.​SocialPostStatusType`](atlas.en-us.apexref.meta/apexref/connectAPI_enums.htm#SocialPostStatusTypeEnum) | Status type. Values are:

-   `ApprovalRecalled`
-   `ApprovalRejected`

-   `Failed`
-   `Hidden`
-   `Pending`
-   `Sent`
-   `Unknown`

 | 36.0 |
