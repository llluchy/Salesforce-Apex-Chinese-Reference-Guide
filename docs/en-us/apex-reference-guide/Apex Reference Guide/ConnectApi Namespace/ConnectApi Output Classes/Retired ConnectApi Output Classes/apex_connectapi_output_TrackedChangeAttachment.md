# ConnectApi.TrackedChangeAttachment

Tracked change attachment to a feed item.

:::tip Important
This class isn’t available in version 32.0 and later. In version 32.0 and
    later, [ConnectApi.TrackedChangesCapability](atlas.en-us.apexref.meta/apexref/apex_connectapi_output_tracked_changes_capability.htm) is used.
:::

| Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `changes` | `List<ConnectApi.​TrackedChange​Item>` | A list of tracked changes. | 28.0–31.0 |
