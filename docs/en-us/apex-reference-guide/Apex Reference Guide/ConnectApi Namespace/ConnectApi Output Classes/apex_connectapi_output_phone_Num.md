# ConnectApi.PhoneNumber

Phone number.

| Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `label` | String | A localized string indicating the phone type. | 30.0 |
| `phoneNumber` | String | Phone number. | 28.0 |
| `phoneType` | String | Phone type. Values are:
-   `Fax`
-   `Mobile`
-   `Work`

These values are not localized.

 | 30.0 |
| `type` | String | This property is not available after version 29.0. Use the `phoneType` property instead. Values are:

-   `Fax`
-   `Mobile`
-   `Work`

These values are not localized.

 | 28.0–29.0 |
