# ConnectApi.AssociatedActionsCapability

If a feed element has this capability, it has platform actions associated with it.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `platformAction​Groups` | [List](atlas.en-us.apexref.meta/apexref/apex_methods_system_list.htm#apex_methods_system_list "Contains methods for the List collection type.")<[`ConnectApi.​PlatformActionGroup`](atlas.en-us.apexref.meta/apexref/apex_connectapi_output_platform_action_group.htm#apex_connectapi_output_platform_action_group "A platform action group instance with state appropriate for the context user.")\> | The platform action groups associated with a feed element. Platform action groups are returned in the order specified in the `ConnectApi.AssociatedActions​CapabilityInput` class. | 33.0 |
