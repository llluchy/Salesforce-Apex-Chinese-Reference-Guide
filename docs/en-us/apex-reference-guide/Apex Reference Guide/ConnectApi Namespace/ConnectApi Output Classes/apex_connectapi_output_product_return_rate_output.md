# ConnectApi.ProductReturnRateOutputRepresentation

Return rate of a product (units returned divided by units sold).

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `productId` | String | ID of the product. | 59.0 |
| `returnRate` | Double | Return rate of specified product. Values range from 0 to 1. | 59.0 |
