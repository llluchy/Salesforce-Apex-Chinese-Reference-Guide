# ConnectApi.GlobalInfluence

Chatter influence.

| Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `percentile` | String | Percentile value for the user’s influence rank within the org or Experience Cloud site. | 28.0 |
| `rank` | Integer | Number indicating the user’s influence rank, relative to all other users within the org or Experience Cloud site. | 28.0 |
