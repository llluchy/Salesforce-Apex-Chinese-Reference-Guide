# ConnectApi.BotVersionActivationInfo

Success or failure information of the bot version activation.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |

| `messages` | [List](atlas.en-us.apexref.meta/apexref/apex_methods_system_list.htm#apex_methods_system_list "Contains methods for the List collection type.")<String> | Failure messages. | 50.0 |
| `success` | Boolean | Indicates whether the activation was successful or not. | 50.0 |
