# ConnectApi.BannerPhoto

A banner photo.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `bannerPhotoUrl` | String | URL to the banner photo in a large format. This URL is available only to authenticated users. | 36.0 |
| `bannerPhoto​VersionId` | String | 18-character version ID of the banner photo. | 36.0 |
| `url` | String | URL to the banner photo. | 36.0 |
