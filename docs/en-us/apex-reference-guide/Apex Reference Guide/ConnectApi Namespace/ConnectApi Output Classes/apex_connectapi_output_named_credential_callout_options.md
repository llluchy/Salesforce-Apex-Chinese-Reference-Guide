# ConnectApi.NamedCredentialCalloutOptions

Named credential callout options.

| Property Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `allowMergeFields​InBody` | Boolean | Specifies whether to allow merge fields in the HTTP body (`true`) or not (`false`). | 58.0 |
| `allowMergeFields​InHeader` | Boolean | Specifies whether to allow merge fields in the HTTP header (`true`) or not (`false`). | 58.0 |
| `generate​AuthorizationHeader` | Boolean | Specifies whether to generate an authorization header (`true`) or not (`false`). | 58.0 |
