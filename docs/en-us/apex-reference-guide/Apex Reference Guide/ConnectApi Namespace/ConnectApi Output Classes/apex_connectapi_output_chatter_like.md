# ConnectApi.ChatterLike

Chatter like information.

| Name | Type | Description | Available Version |
| --- | --- | --- | --- |
| `id` | String | Like’s 18-character ID | 28.0 |
| `likedItem` | `ConnectApi.​Reference` | A reference to the liked comment or feed element. | 28.0 |
| `url` | String | Like’s Connect REST API URL | 28.0 |
| `user` | `ConnectApi.​User​Summary` | Like’s creator | 28.0 |
