# DataWeave Namespace

The DataWeave namespace provides classes and methods to support the invocation of DataWeave scripts from Apex.

DataWeave is the MuleSoft expression language for accessing, parsing, and transforming data that travels through a Mule application. For detailed information, see [DataWeave Language](https://docs.mulesoft.com/mule-runtime/4.3/dataweave).

These are the classes in the `DataWeave` namespace.
