# PaymentInitiationPixKeyType Enum

Represents the type of PIX key used for a payment.

## Enum Values

The following are the values of the `RichMessaging.PaymentInitiationPixKeyType` enum.

| Value | Description |
| --- | --- |
| `Cpf` | Represents a PIX key type using CPF (Cadastro de Pessoas Físicas). |
| `Cnpj` | Represents a PIX key type using CNPJ (Cadastro Nacional da Pessoa Jurídica). |
| `Email` | Represents a PIX key type using email address. |
| `Phone` | Represents a PIX key type using phone number. |
| `Evp` | Represents a PIX key type using EVP (Endereço Virtual de Pagamento). |
