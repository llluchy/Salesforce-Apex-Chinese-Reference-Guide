# PaymentTransactionType Enum

Represents the type of payment transaction.

## Enum Values

The following are the values of the `RichMessaging.PaymentTransactionType` enum.

| Value | Description |
| --- | --- |
| `Sale` | Represents a sale transaction. |
| `Refund` | Represents a refund transaction. |
| `Authorization` | Represents an authorization transaction. |
| `Capture` | Represents a capture transaction. |
| `Void` | Represents a void transaction. |
