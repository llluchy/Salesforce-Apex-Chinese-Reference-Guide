# PaymentCheckoutBehavior Enum

Represents the checkout behavior of a payment.

## Enum Values

The following are the values of the `RichMessaging.PaymentCheckoutBehavior` enum.

| Value | Description |
| --- | --- |
| `ReviewAndPay` | Represents a checkout behavior where the customer reviews before paying. |
| `QuickPay` | Represents a quick pay checkout behavior without review. |
