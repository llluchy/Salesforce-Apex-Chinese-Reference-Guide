# OrderItemCategory Enum

Represents the category of an order item.

## Enum Values

The following are the values of the `RichMessaging.OrderItemCategory` enum.

| Value | Description |
| --- | --- |
| `Product` | Represents a product category for the order item. |
| `Tax` | Represents a tax category for the order item. |
| `Fee` | Represents a fee category for the order item. |
