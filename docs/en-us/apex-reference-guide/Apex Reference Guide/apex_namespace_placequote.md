# PlaceQuote Namespace

The `PlaceQuote` namespace provides classes and methods to create or update quotes with pricing preferences and configuration options.

See [PlaceQuote namespace](https://developer.salesforce.com/docs/atlas.en-us.262.0.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/apex_namespace_placequote.htm "HTML (New Window)") for more information about the available classes and methods.
