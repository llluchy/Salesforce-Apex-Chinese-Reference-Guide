# Get Started with the Apex Connector Framework

To get started with your first custom adapter for Salesforce Connect, create two Apex classes: one that extends the `DataSource.Connection` class, and one that extends the `DataSource.Provider` class.

:::tip Note
The `DataSource.Connection` class requires a
   Salesforce Connect add-on license. For more information, see [Salesforce Connect Adapters Included per
    Add-On License](https://help.salesforce.com/s/articleView?id=sf.platform_connect_license.htm&language=en_US).
:::
