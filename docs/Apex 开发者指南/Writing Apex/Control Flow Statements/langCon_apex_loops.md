# Loops

Apex supports five types of procedural loops.

These types of procedural loops are supported:

-   [`do {statement} while (Boolean_condition);`](atlas.en-us.apexcode.meta/apexcode/langCon_apex_loops_do_while.htm)
-   [`while (Boolean_condition) statement;`](atlas.en-us.apexcode.meta/apexcode/langCon_apex_loops_while.htm)
-   [`for (initialization; Boolean_exit_condition; increment) statement;`](atlas.en-us.apexcode.meta/apexcode/langCon_apex_loops_for.htm)
-   [`for (variable : array_or_set) statement;`](atlas.en-us.apexcode.meta/apexcode/langCon_apex_loops_for_lists.htm)
-   [`for (variable : [inline_soql_query]) statement;`](atlas.en-us.apexcode.meta/apexcode/langCon_apex_loops_for_SOQL.htm "SOQL for loops iterate over all of the sObject records returned by a SOQL query.")

All loops allow for loop control structures:

-   `break;` exits the entire loop
-   `continue;` skips to the next iteration of the loop
