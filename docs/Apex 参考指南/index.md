# Apex 参考指南

> **英文原文**: [Apex Reference Guide](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_ref_guide.htm)

本部分是 Salesforce Apex Reference Guide 的中文翻译,涵盖所有 Apex 命名空间下的类、接口、枚举的参考文档。

## 命名空间列表

| 命名空间 | 说明 |
|---------|------|
| System | Apex 核心系统类,包含基础数据类型和常用方法 |
| ApexPages | Visualforce 页面控制器相关类 |
| Auth | 身份认证相关类和接口 |
| Cache | 平台缓存相关类 |
| Database | 数据库操作相关类 |

::: tip 说明
本页面为目录索引页。在左侧侧边栏中点击各命名空间节点可展开查看其中的类、接口、枚举等文档,支持无限嵌套。
:::
