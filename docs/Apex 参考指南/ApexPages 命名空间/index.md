# ApexPages 命名空间

> **英文原文**: [ApexPages Namespace](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_namespace_apexpages.htm)

ApexPages 命名空间包含用于 Visualforce 控制器的类和接口。

## 包含的类与接口

- Action Class
- Component Class
- Message Class
- StandardController Class
- StandardSetController Class
