# Database 类

> **英文原文**: [Database Class](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_methods_system_database.htm)

## 说明

`Database` 类提供在 Apex 中执行 DML 操作的方法,包括插入、更新、删除、查询等。

## 子主题

- [常用方法](./常用方法) - insert、update、delete、query 等方法详解
- Database.SaveResult - 保存操作结果
- Database.UpsertResult - upsert 操作结果
- Database.DeleteResult - 删除操作结果
