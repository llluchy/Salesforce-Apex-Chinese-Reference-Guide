# Database 常用方法

> **英文原文**: [Database Methods](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_methods_system_database.htm)

## insert(records, allOrNone)

将记录插入数据库。

```apex
public static Database.SaveResult[] insert(sObject[] records, Boolean allOrNone)
```

## update(records, allOrNone)

更新数据库中的记录。

```apex
public static Database.SaveResult[] update(sObject[] records, Boolean allOrNone)
```

## delete(records, allOrNone)

从数据库中删除记录。

```apex
public static Database.DeleteResult[] delete(sObject[] records, Boolean allOrNone)
```

## query(queryString)

执行 SOQL 查询并返回结果。

```apex
public static sObject[] query(String queryString)
```
