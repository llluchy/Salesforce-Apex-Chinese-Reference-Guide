# System 命名空间

> **英文原文**: [System Namespace](https://developer.salesforce.com/docs/atlas.en-us.apexref.meta/apexref/apex_ref_system.htm)

System 命名空间包含 Apex 的核心类和接口,提供基础数据类型、集合、异常处理、数据库操作等核心功能。

## 包含的类与接口

- AccessLevel 类 - 访问级别控制
- Database 类 - 数据库操作
- String 类 - 字符串操作
- Integer 类 - 整数操作
- Boolean 类 - 布尔值操作
